# Execution Plan: LLM-Coordinated Drone Swarm Experiment
## Comparing State Representation Schemes for LLM-Based Swarm Planning

---

## Overview

This document is a self-contained execution plan for a Claude instance (or any LLM-assisted developer) to implement and run the first experimental phase of a thesis project. The goal is to evaluate how different **state space representations** of a drone swarm affect the quality of plans generated by a Large Language Model acting as a **global planner**.

The LLM receives a description of the swarm state once, generates a Python plan, and the simulator executes it. No closed-loop feedback is used in this phase.

---

## Research Question

> Do different ways of representing the swarm's configuration space (raw coordinates, relative coordinates, graph-based, aggregate descriptors, semantic natural language) lead to measurably different planning quality when used as LLM context?

**Independent variable:** State representation scheme (5 variants)  
**Dependent variable:** Task reward (formation quality), code validity rate  
**Controlled variables:** Task, LLM model, temperature, random seeds  
**Scaling variable:** Number of drones N ∈ {3, 6, 10, 15}

---

### Step 1.2 — Write the simulation wrapper

Create `simulator.py`. This file owns all interaction with the simulator and must expose a clean interface to the rest of the codebase.

```python
# simulator.py
import numpy as np
from gym_pybullet_drones.envs.CtrlAviary import CtrlAviary
from gym_pybullet_drones.utils.enums import DroneModel, Physics

class SwarmSimulator:
    def __init__(self, n_drones: int, gui: bool = False):
        self.n_drones = n_drones
        self.env = CtrlAviary(
            drone_model=DroneModel.CF2X,
            num_drones=n_drones,
            physics=Physics.PYB,
            gui=gui,
            record=False,
        )

    def reset(self, seed: int = 0) -> dict:
        """Reset environment and return initial state as a dict."""
        np.random.seed(seed)
        obs, _ = self.env.reset(seed=seed)
        return self._parse_obs(obs)

    def execute_plan(self, target_positions: dict) -> dict:
        """
        Execute a plan by stepping the simulator toward target positions.
        target_positions: {drone_id (int): (x, y, z)}
        Returns the final state after execution.
        """
        # Simple approach: run for T steps with PID toward targets
        # For now, directly return target as final state (placeholder)
        # Replace with actual PID stepping in a later iteration
        return {"positions": target_positions}

    def _parse_obs(self, obs) -> dict:
        """Parse raw gym observation into a clean state dict."""
        positions = {}
        velocities = {}
        for i in range(self.n_drones):
            # gym-pybullet-drones obs shape: (n_drones, 20)
            # positions are indices 0:3
            positions[i] = tuple(obs[i, 0:3].tolist())
            velocities[i] = tuple(obs[i, 10:13].tolist())
        return {
            "n_drones": self.n_drones,
            "positions": positions,
            "velocities": velocities,
        }

    def close(self):
        self.env.close()
```

**Checkpoint:** instantiate `SwarmSimulator(n_drones=3)`, call `.reset(seed=42)`, print the state dict. Positions should be 3D tuples near the origin.

### Step 1.3 — Write the reward function

Create `reward.py`. The reward measures how well the final drone positions match the target formation. Uses the Hungarian algorithm to find the optimal drone-to-slot assignment before computing distance.

```python
# reward.py
import numpy as np
from scipy.optimize import linear_sum_assignment

def circle_formation_targets(n: int, radius: float = 2.0, height: float = 1.0) -> list:
    """Generate target positions for a circle formation."""
    angles = np.linspace(0, 2 * np.pi, n, endpoint=False)
    return [(radius * np.cos(a), radius * np.sin(a), height) for a in angles]

def formation_reward(final_positions: dict, target_positions: list) -> float:
    """
    Compute reward as negative mean distance after optimal assignment.
    Returns a value in [-inf, 0], where 0 is perfect formation.
    """
    n = len(final_positions)
    assert len(target_positions) == n, "Mismatch between drones and targets"

    # Build cost matrix: cost[i][j] = distance from drone i to target slot j
    drone_ids = sorted(final_positions.keys())
    cost_matrix = np.zeros((n, n))
    for i, d_id in enumerate(drone_ids):
        for j, target in enumerate(target_positions):
            pos = np.array(final_positions[d_id])
            tgt = np.array(target)
            cost_matrix[i, j] = np.linalg.norm(pos - tgt)

    # Hungarian algorithm: find optimal assignment
    row_ind, col_ind = linear_sum_assignment(cost_matrix)
    mean_distance = cost_matrix[row_ind, col_ind].mean()

    # Reward: higher is better (negative distance)
    return -mean_distance
```

**Checkpoint:** generate 5 random positions and 5 circle targets, verify reward is negative and improves as positions approach targets.

### Step 1.4 — Write the code executor (safe sandbox)

Create `executor.py`. The LLM will return Python code as a string. This module executes it safely and extracts the target positions.

```python
# executor.py
import re
import traceback

def extract_code_block(llm_response: str) -> str:
    """Extract Python code from LLM response (handles ```python ... ``` blocks)."""
    pattern = r"```python\s*(.*?)\s*```"
    match = re.search(pattern, llm_response, re.DOTALL)
    if match:
        return match.group(1).strip()
    # If no code block markers, assume entire response is code
    return llm_response.strip()

def execute_plan_code(code: str, state: dict) -> dict | None:
    """
    Execute LLM-generated code and return target positions.
    Returns None if execution fails.

    The code is expected to define a function called `plan(state)`
    that returns a dict {drone_id (int): (x, y, z)}.
    """
    local_namespace = {}
    try:
        exec(code, {}, local_namespace)
        if "plan" not in local_namespace:
            print("ERROR: No 'plan' function found in generated code.")
            return None
        result = local_namespace["plan"](state)
        # Validate output format
        assert isinstance(result, dict), "plan() must return a dict"
        for k, v in result.items():
            assert isinstance(k, int), f"Keys must be int drone IDs, got {type(k)}"
            assert len(v) == 3, f"Values must be (x, y, z) tuples, got {v}"
        return result
    except Exception as e:
        print(f"ERROR executing plan code: {e}")
        print(traceback.format_exc())
        return None
```

**Checkpoint:** write a hardcoded plan string (a Python function that moves drones to fixed positions), pass it through `execute_plan_code`, verify it returns the expected dict.

## Phase 2 — State Representations

Create `representations.py`. Each function takes the same `state` dict from the simulator and returns a string for the LLM prompt.

### Representation 1: Raw Coordinates

```python
def repr_raw(state: dict) -> str:
    lines = [f"Number of drones: {state['n_drones']}"]
    lines.append("Drone positions (x, y, z) in meters:")
    for drone_id, pos in state["positions"].items():
        lines.append(f"  Drone {drone_id}: ({pos[0]:.3f}, {pos[1]:.3f}, {pos[2]:.3f})")
    return "\n".join(lines)
```

### Representation 2: Centroid-Relative Coordinates

```python
import numpy as np

def repr_relative(state: dict) -> str:
    positions = state["positions"]
    centroid = np.mean([np.array(p) for p in positions.values()], axis=0)
    lines = [
        f"Number of drones: {state['n_drones']}",
        f"Swarm centroid: ({centroid[0]:.3f}, {centroid[1]:.3f}, {centroid[2]:.3f})",
        "Drone positions relative to centroid (dx, dy, dz):"
    ]
    for drone_id, pos in positions.items():
        rel = np.array(pos) - centroid
        lines.append(f"  Drone {drone_id}: ({rel[0]:.3f}, {rel[1]:.3f}, {rel[2]:.3f})")
    return "\n".join(lines)
```

### Representation 3: Neighborhood Graph

```python
def repr_graph(state: dict, neighbor_radius: float = 2.0) -> str:
    positions = state["positions"]
    n = state["n_drones"]
    lines = [
        f"Number of drones: {n}",
        f"Neighbor radius: {neighbor_radius}m",
        "Drone positions and neighbors:"
    ]
    for i, pos_i in positions.items():
        neighbors = []
        for j, pos_j in positions.items():
            if i == j:
                continue
            dist = np.linalg.norm(np.array(pos_i) - np.array(pos_j))
            if dist <= neighbor_radius:
                neighbors.append(f"Drone {j} ({dist:.2f}m away)")
        lines.append(
            f"  Drone {i} at ({pos_i[0]:.2f}, {pos_i[1]:.2f}, {pos_i[2]:.2f}): "
            f"neighbors = [{', '.join(neighbors) if neighbors else 'none'}]"
        )
    return "\n".join(lines)
```

### Representation 4: Aggregate Descriptors

```python
def repr_aggregate(state: dict) -> str:
    positions = np.array(list(state["positions"].values()))
    centroid = positions.mean(axis=0)
    spread = positions.std(axis=0)
    max_dist = max(
        np.linalg.norm(positions[i] - positions[j])
        for i in range(len(positions))
        for j in range(i + 1, len(positions))
    ) if len(positions) > 1 else 0.0

    lines = [
        f"Number of drones: {state['n_drones']}",
        f"Swarm centroid: ({centroid[0]:.3f}, {centroid[1]:.3f}, {centroid[2]:.3f})",
        f"Position spread (std): ({spread[0]:.3f}, {spread[1]:.3f}, {spread[2]:.3f})",
        f"Maximum inter-drone distance: {max_dist:.3f}m",
        f"Mean height: {centroid[2]:.3f}m",
    ]
    return "\n".join(lines)
```

### Representation 5: Natural Language (Semantic)

```python
def repr_natural_language(state: dict) -> str:
    positions = state["positions"]
    n = state["n_drones"]
    pos_array = np.array(list(positions.values()))
    centroid = pos_array.mean(axis=0)

    quadrant_counts = {"north-east": 0, "north-west": 0, "south-east": 0, "south-west": 0}
    for pos in positions.values():
        q = ("north" if pos[1] > centroid[1] else "south") + \
            "-" + ("east" if pos[0] > centroid[0] else "west")
        quadrant_counts[q] += 1

    spread = pos_array.std()
    spread_desc = "tightly clustered" if spread < 0.5 else ("moderately spread" if spread < 1.5 else "widely dispersed")

    qdesc = ", ".join(f"{v} drone(s) in the {k}" for k, v in quadrant_counts.items() if v > 0)
    return (
        f"There are {n} drones currently {spread_desc} around their centroid "
        f"at approximately ({centroid[0]:.1f}, {centroid[1]:.1f}, {centroid[2]:.1f}) meters. "
        f"Distribution: {qdesc}."
    )
```

```python
# llm_connector.py

# ── Option A: Groq (recommended for development) ──────────────────────────
from groq import Groq

def get_completion_groq(prompt: str) -> str:
    client = Groq(api_key="YOUR_GROQ_API_KEY")
    response = client.chat.completions.create(
        model="llama-3.3-70b-versatile",
        messages=[{"role": "user", "content": prompt}],
        temperature=0,
    )
    return response.choices[0].message.content

# ── Option B: Gemini Flash (recommended for pilot experiment) ──────────────
import google.generativeai as genai

def get_completion_gemini(prompt: str) -> str:
    genai.configure(api_key="YOUR_GEMINI_API_KEY")
    model = genai.GenerativeModel(
        "gemini-2.0-flash",
        generation_config={"temperature": 0}
    )
    response = model.generate_content(prompt)
    return response.text

# ── Option C: Claude (recommended for full experiment) ─────────────────────
import anthropic

def get_completion_claude(prompt: str) -> str:
    client = anthropic.Anthropic(api_key="YOUR_ANTHROPIC_API_KEY")
    response = client.messages.create(
        model="claude-sonnet-4-20250514",
        max_tokens=1500,
        messages=[{"role": "user", "content": prompt}],
    )
    return response.content[0].text

# ── Active connector (change this line to switch models) ───────────────────
get_completion = get_completion_groq
```

## Phase 5 — Main Experiment Loop

Create `experiment.py`. Orchestrates everything: runs trials, logs results, computes reward.

```python
# experiment.py
import json
import time
from datetime import datetime
from pathlib import Path

from simulator import SwarmSimulator
from representations import REPRESENTATIONS
from reward import circle_formation_targets, formation_reward
from executor import extract_code_block, execute_plan_code
from prompt_builder import build_prompt, TASK_CIRCLE
from llm_connector import get_completion

def run_trial(
    n_drones: int,
    representation_name: str,
    seed: int,
    task_description: str = TASK_CIRCLE,
) -> dict:
    """Run a single trial and return a result dict."""
    sim = SwarmSimulator(n_drones=n_drones, gui=False)
    state = sim.reset(seed=seed)

    repr_fn = REPRESENTATIONS[representation_name]
    state_text = repr_fn(state)
    prompt = build_prompt(state_text, task_description, n_drones)

    t0 = time.time()
    llm_response = get_completion(prompt)
    latency = time.time() - t0

    code = extract_code_block(llm_response)
    target_positions = execute_plan_code(code, state)

    if target_positions is None:
        reward = None
        valid = False
    else:
        targets = circle_formation_targets(n_drones)
        reward = formation_reward(target_positions, targets)
        valid = True

    sim.close()

    return {
        "timestamp": datetime.now().isoformat(),
        "n_drones": n_drones,
        "representation": representation_name,
        "seed": seed,
        "prompt": prompt,
        "llm_response": llm_response,
        "code": code,
        "valid_code": valid,
        "reward": reward,
        "latency_s": latency,
    }

def run_experiment(
    n_drones_list: list = [3, 6, 10, 15],
    representations: list = list(REPRESENTATIONS.keys()),
    seeds: list = list(range(20)),
    output_dir: str = "results",
):
    Path(output_dir).mkdir(exist_ok=True)
    all_results = []

    total = len(n_drones_list) * len(representations) * len(seeds)
    done = 0

    for n in n_drones_list:
        for repr_name in representations:
            for seed in seeds:
                print(f"[{done+1}/{total}] N={n}, repr={repr_name}, seed={seed}")
                try:
                    result = run_trial(n, repr_name, seed)
                except Exception as e:
                    result = {
                        "n_drones": n, "representation": repr_name,
                        "seed": seed, "error": str(e), "reward": None, "valid_code": False
                    }
                all_results.append(result)
                done += 1

                # Save incrementally (safe against crashes)
                with open(f"{output_dir}/results.json", "w") as f:
                    json.dump(all_results, f, indent=2)

    print(f"\nDone. {done} trials saved to {output_dir}/results.json")
    return all_results

if __name__ == "__main__":
    # Start with a small pilot: N=3, all representations, 5 seeds
    run_experiment(
        n_drones_list=[3],
        representations=list(REPRESENTATIONS.keys()),
        seeds=list(range(5)),
        output_dir="results_pilot",
    )
```

## Phase 6 — Analysis

Create `analysis.py`. Loads results and produces summary statistics and plots.

```python
# analysis.py
import json
import numpy as np
import matplotlib.pyplot as plt
from collections import defaultdict

def load_results(path: str = "results/results.json") -> list:
    with open(path) as f:
        return json.load(f)

def summarize(results: list) -> dict:
    """Compute mean reward and validity rate per (n_drones, representation)."""
    groups = defaultdict(list)
    for r in results:
        key = (r["n_drones"], r["representation"])
        groups[key].append(r)

    summary = {}
    for (n, repr_name), trials in groups.items():
        rewards = [t["reward"] for t in trials if t["reward"] is not None]
        valid_count = sum(1 for t in trials if t["valid_code"])
        summary[(n, repr_name)] = {
            "mean_reward": np.mean(rewards) if rewards else None,
            "std_reward": np.std(rewards) if rewards else None,
            "validity_rate": valid_count / len(trials),
            "n_trials": len(trials),
        }
    return summary

def plot_reward_vs_n(summary: dict, representations: list, save_path: str = None):
    """Plot mean reward vs N for each representation."""
    n_values = sorted(set(n for (n, _) in summary.keys()))

    fig, ax = plt.subplots(figsize=(8, 5))
    for repr_name in representations:
        means = []
        stds = []
        for n in n_values:
            key = (n, repr_name)
            if key in summary and summary[key]["mean_reward"] is not None:
                means.append(summary[key]["mean_reward"])
                stds.append(summary[key]["std_reward"])
            else:
                means.append(None)
                stds.append(None)

        valid_n = [n for n, m in zip(n_values, means) if m is not None]
        valid_means = [m for m in means if m is not None]
        valid_stds = [s for s in stds if s is not None]

        ax.plot(valid_n, valid_means, marker="o", label=repr_name)
        ax.fill_between(
            valid_n,
            [m - s for m, s in zip(valid_means, valid_stds)],
            [m + s for m, s in zip(valid_means, valid_stds)],
            alpha=0.15,
        )

    ax.set_xlabel("Number of drones (N)")
    ax.set_ylabel("Mean reward (higher is better)")
    ax.set_title("LLM Planning Quality vs Swarm Size\nby State Representation")
    ax.legend()
    ax.grid(True, alpha=0.3)
    plt.tight_layout()

    if save_path:
        plt.savefig(save_path, dpi=150)
    plt.show()

if __name__ == "__main__":
    results = load_results("results_pilot/results.json")
    summary = summarize(results)

    print("\n=== Summary ===")
    for (n, repr_name), stats in sorted(summary.items()):
        print(
            f"N={n:2d} | {repr_name:20s} | "
            f"reward={stats['mean_reward']:+.3f} ± {stats['std_reward']:.3f} | "
            f"valid={stats['validity_rate']*100:.0f}%"
        )
```

- No representations produce identical results (confirms they are actually different)

If code validity rate is low, inspect the raw LLM responses in `results.json` and adjust the prompt in `prompt_builder.py`.

## Common Issues and Fixes

**`pybullet` install fails on Mac ARM**
```bash
pip install pybullet --no-binary pybullet
```

**LLM returns code without ```python markers**
The `extract_code_block` function falls back to returning the full response. Add a line to the prompt: *"Always wrap your code in ```python ... ``` markers."*

**`execute_plan_code` returns None for valid-looking code**
Add print statements inside `execute_plan_code` to see the exact exception. Common issues: LLM uses `drone_id` as string instead of int, or returns a list instead of a dict.

**Reward is always -0.000 (perfect)**
The task is too easy for N=3 with raw coordinates — try increasing N or randomizing initial positions across a wider range.

**Rate limit errors on Groq/Gemini**
Add `time.sleep(1)` between trials in `run_experiment()`.
